Aula 0 · Configuração do Ambiente

Como Instalar Python, VSCode e Jupyter Notebook Para Programar do Zero

Antes de começarmos a programar de verdade, precisamos preparar nosso ambiente de desenvolvimento. Neste artigo você vai aprender passo a passo como instalar tudo que será necessário para programar em Python da forma correta, mesmo que nunca tenha mexido com programação antes.

Lista do que vamos instalar:
  • Python
  • VSCode
  • Extensão Python
  • Extensão Jupyter
  • Extensões Adicionais
📍

Instalando o Python

O primeiro passo para começarmos nossa jornada na programação com Python é instalar a linguagem em nosso computador.

Para isso, acesse o site oficial do Python e realize o download da versão estável mais recente disponível. Utilizar a versão mais atual garante que você terá acesso aos recursos mais modernos da linguagem, além de correções de segurança e melhorias de desempenho importantes para o desenvolvimento.

Instalando o VSCode

Com o Python devidamente instalado e validado, nosso próximo passo será instalar o VSCode (Visual Studio Code). O VSCode é um editor de código profissional amplamente utilizado por programadores no mundo inteiro, sendo uma das ferramentas mais populares atualmente para desenvolvimento de software.

Ele será o ambiente que utilizaremos para escrever, organizar e executar nossos códigos durante toda nossa jornada de aprendizado com Python.

🔗

Instalando a Extensão Python

Após concluir a instalação do VSCode, precisamos preparar o editor para reconhecer e trabalhar corretamente com a linguagem Python. Para isso, instalaremos a extensão oficial do Python, disponibilizada pela própria Microsoft dentro da loja de extensões do VSCode.

Essa extensão adiciona diversos recursos importantes ao editor:

✅
→ Reconhecimento de sintaxe da linguagem
→ Sugestões automáticas de código
→ Integração com o interpretador Python
→ Ferramentas de depuração
→ Execução facilitada de scripts

Para instalá-la, abra o VSCode e clique no menu lateral de Extensões, ou utilize o atalho Ctrl + Shift + X. Em seguida, pesquise por Python, localize a extensão oficial desenvolvida pela Microsoft e clique em Install.

☝️
Observação: no meu caso, o botão aparece como "Switch to Pre-Release Version" porque já possuo o Python instalado. Na sua primeira instalação, aparecerá apenas o botão Install, que é a opção correta.

Instalando a Extensão Jupyter

Com a extensão do Python devidamente instalada, nosso próximo passo será adicionar também a extensão Jupyter ao VSCode. Essa extensão permite utilizar arquivos interativos conhecidos como Notebooks, onde podemos executar códigos em blocos separados, facilitando muito o aprendizado e os testes durante a programação.

Para instalar, abra novamente a aba de Extensões com Ctrl + Shift + X, pesquise por Jupyter, selecione a versão oficial da Microsoft e clique em Install.

☝️
Observação: assim como na extensão anterior, no meu caso o botão aparece diferente por já ter o ambiente configurado. Na sua primeira instalação aparecerá o botão Install normalmente. Não se preocupe com pequenas diferenças visuais.

Extensões Opcionais Recomendadas

Além das extensões principais, existem algumas extensões adicionais que melhora bastante a experiência durante os estudos e no dia a dia como programador.

🎨 Dracula Theme Official
Altera o tema visual do VSCode, deixando o editor mais moderno e agradável durante longos períodos de estudo.
📁 Material Icon Theme
Altera os ícones das pastas e arquivos, tornando a interface mais organizada e intuitiva.
⚙️ Python Indent
Auxilia automaticamente na indentação correta de códigos Python, essencial para iniciantes.
🌐 Python Environments
Facilita o gerenciamento de ambientes Python. Muito útil quando começar a usar ambientes virtuais.
🐛 Python Debugger
Permite executar seu programa em modo de debug, facilitando a identificação de erros e comportamentos inesperados.
🧠 Pylance
Melhora drasticamente a inteligência do editor com autocompletar avançado, validação de código e sugestões inteligentes.

📍 Conclusão do Primeiro Passo

Parabéns, o primeiro passo da sua jornada foi concluído com sucesso. Seu ambiente de desenvolvimento agora está totalmente preparado e pronto para que possamos iniciar nossos estudos práticos em Python nos próximos conteúdos.

Um pequeno progresso diário, quando acumulado ao longo de meses e anos, pode gerar resultados gigantescos no futuro. Trate seu aprendizado como um trabalho de formiguinha: um passo de cada vez, um pouco por dia, sempre evoluindo.
